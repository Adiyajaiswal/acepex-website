# ACEPEX site – deploy and SEO checklist

Upload this whole folder to your Vercel project (replace the old files).

## After deploying
1. Google Search Console: add the property, paste the verification tag in index.html (see the comment in the head), then submit sitemap.xml.
2. Request indexing of the home page in Search Console.
3. Create a Google Business Profile (adds Maps and local results).
4. Connect your own domain in Vercel (for example acepex.in) and update the URL in index.html, sitemap.xml, robots.txt and the JSON-LD.
5. Add ACEPEX to LinkedIn, Clutch, GoodFirms, Justdial and similar directories, linking to the site. Backlinks are a major ranking factor.
6. Test: search.google.com/test/rich-results, pagespeed.web.dev, opengraph.xyz.

## Growth
Create one page per service (Real estate CRM, Hostel management software, WhatsApp automation) and add real case studies. Each page can rank for its own search terms.
